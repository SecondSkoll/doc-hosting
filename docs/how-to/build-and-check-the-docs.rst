Build and check the documentation
=================================

Install the locked documentation dependencies:

.. code-block:: bash

   uv sync --group docs

Build ``dirhtml`` with warnings treated as errors:

.. code-block:: bash

   uv run --group docs sphinx-build --fail-on-warning --keep-going \
     -b dirhtml docs docs/_build

Check links:

.. code-block:: bash

   uv run --group docs sphinx-build -b linkcheck -q docs docs/_build/linkcheck

Check spelling and style with the repository's Vale configuration after it has
been generated by the documentation tooling:

.. code-block:: bash

   uv run --group docs vale --config=docs/_dev/vale.ini \
     --glob='*.{md,rst}' README.md docs

The optional accessibility check additionally needs npm and a local Chrome or
Chromium installation. The repository's ``docs/Makefile`` exposes the full set
of Canonical Sphinx Stack targets for CI and maintainers.
